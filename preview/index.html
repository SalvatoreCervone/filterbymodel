Tabella Ponte

Il nome della tabella che memorizza le associazioni multiple (es. anagrafica_ufficio o utente_ruolo).

Rif. Scheda

Il campo nella tabella ponte che identifica la scheda (es. anagrafica_id).

Rif. Filtro

Il campo nella tabella ponte che contiene l'ufficio/qualifica (es. ufficio_id).

Default: 'id'

Lascia vuoto questo campo se la scheda usa il normale numero identificativo progressivo (id). Compilalo solo se il collegamento usa un codice speciale (es. codice_fiscale).

Ecco come il sistema traduce visivamente questa regola nella query finale al database.

SELECT * FROM {{ targetTableName }} WHERE ( {{ targetTableName }}.{{ form.filter_key || 'colonna_filtro' }} IN (:elenco_id_autorizzati_utente)
AND {{ additionalWhereSql }} {{ targetTableName }}.{{ form.target_foreign_key || 'id' }} IN ( SELECT {{ form.pivot_foreign_key || 'colonna_scheda' }} FROM {{ form.pivot_table || 'tabella_ponte' }} WHERE {{ form.pivot_table || 'tabella_ponte' }}.{{ form.filter_key || 'colonna_filtro' }} IN (:elenco_id_autorizzati_utente)
AND {{ additionalWhereSql }} ) )
// Verifica se il valore appartiene alle competenze dell'utente: if (!in_array($record->{{ form.filter_key || 'colonna_filtro' }}, $idAutorizzatiUtente)) { throw ValidationException::withMessages(['authorization' => 'Non puoi modificare questo record.']); } // Verifica associazione su tabella ponte: $autorizzato = DB::table('{{ form.pivot_table || 'tabella_ponte' }}') ->where('{{ form.pivot_foreign_key || 'colonna_scheda' }}', $record->{{ form.target_foreign_key ? form.target_foreign_key : 'getKey()' }}) ->whereIn('{{ form.filter_key || 'colonna_filtro' }}', $idAutorizzatiUtente) ->exists();
